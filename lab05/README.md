# Практическая работа №5: Кванторы, EXISTS и реляционное деление

## Выполнил
- ФИО: Газдиева Л.М.
- Группа: ИНБО-21-23
- Вариант: 6 (S = PA, AM, RO)

## Постановка
Найти категории товаров, встречавшиеся в доставленных заказах покупателей каждого из трёх штатов: **PA, AM, RO**.

## Реализации

**1. Двойной NOT EXISTS.** «Не существует штата из S, в котором категория не продавалась.» Проверка идёт по `product_category_name`, а не по `product_id` — иначе условие становится строже («каждый товар категории продавался во всех штатах»).

**2. GROUP BY / HAVING COUNT(DISTINCT).** Считаем число разных штатов, где встречалась категория. Если = мощности S (3) — категория продавалась во всех. `COUNT(DISTINCT)` обязателен, иначе один штат с множеством заказов «перевесит».

**3. EXCEPT.** Из всех категорий вычитаем те, для которых есть штат из S без продажи.

## Эквивалентность
`r1 EXCEPT r2` = **0** и `r2 EXCEPT r1` = **0** → все три реализации дают одинаковый результат.

## Диагностика (п.6)
Категория **artes**: AM — 1 заказ, PA — 2, RO — 2. Все три штата присутствуют.

## Пустой target_states (п.7)
- **NOT EXISTS** → **все категории** (vacuous truth: «для всех x ∈ ∅ условие истинно»).
- **GROUP BY / HAVING** → **0 строк** (после фильтра `state IN (∅)` нет строк).

Расхождение — важный семантический нюанс. По теории реляционного деления корректно поведение NOT EXISTS.

## Продавцы (п.8)
Найдено **25 продавцов**, продававших товары покупателям каждого из трёх штатов.

## Контрольные вопросы

**1.** `∀x P(x)` ≡ `¬∃x ¬P(x)` — «не существует x, для которого P(x) ложно». В SQL — двойной NOT EXISTS.

**2.** COUNT(DISTINCT state) считает разные штаты, где была категория. Сравнение с мощностью делителя гарантирует «во всех». Без DISTINCT один штат с множеством заказов даст завышенное число.

**3.** «Для всех x ∈ ∅ выполняется P(x)» — истинно по определению (vacuous truth). Поэтому NOT EXISTS вернёт все объекты, а GROUP BY/HAVING — 0 строк.
